# MD Viewer 사용설명서

마크다운(`.md`)과 PDF 문서를 **작성자의 의도대로** 읽기 위한 단독 실행 데스크톱 뷰어다.
수식·다이어그램·표·코드 하이라이트를 그대로 렌더링하고, 폴더 단위로 문서를 오가며 읽는다.
**읽기 중심 뷰어**다 — 기본은 읽기 전용이고, 편집 모드를 켰을 때만 문서를 고칠 수 있다.

- 설치: [macOS](#1-설치--macos) · [Windows](#2-설치--windows) · [Linux](#3-설치--linux)
- [처음 사용하기](#4-처음-사용하기) · [화면 구성](#5-화면-구성)
- [기능별 사용법](#6-기능별-사용법) · [단축키](#7-단축키) · [문제 해결](#8-문제-해결)

## 1. 설치 — macOS

**대상**: Apple Silicon(M1 이상). 현재 릴리스에는 **Intel Mac용 빌드가 없다.**

1. [Releases](https://github.com/KIMHeeKwon/MD-Viewer/releases/latest)에서
   `MD-Viewer-<버전>-arm64.dmg`를 내려받는다.
2. dmg를 열고 **MD Viewer**를 **응용 프로그램** 폴더로 끌어다 놓는다.
3. 처음 실행할 때 경고가 나온다. 이 앱은 Apple 코드 서명·공증이 없기 때문이며,
   앱이 손상된 것은 아니다. 아래 둘 중 하나로 해결한다.

**방법 A — 우클릭으로 열기** (권장, 한 번만)

응용 프로그램 폴더에서 **MD Viewer를 우클릭 → 열기** → 대화상자에서 다시 **열기**.

**방법 B — "손상되었으므로 휴지통으로 이동" 경고가 나오는 경우**

터미널에서 격리(quarantine) 속성을 제거한다.

```bash
xattr -dr com.apple.quarantine "/Applications/MD Viewer.app"
```

### 파일 연결 (선택)

Finder에서 `.md` 파일을 **우클릭 → 다음으로 열기 → MD Viewer**. "항상 이 응용 프로그램으로
열기"를 지정하면 이후 더블클릭으로 바로 열린다.

### 제거

응용 프로그램 폴더에서 **MD Viewer를 휴지통으로 이동**. 설정까지 지우려면 아래도 삭제한다.

```
~/Library/Application Support/MD Viewer
~/Library/Preferences/kr.hkkim.mdviewer.plist
```

## 2. 설치 — Windows

1. [Releases](https://github.com/KIMHeeKwon/MD-Viewer/releases/latest)에서
   `MD-Viewer-Setup-<버전>.exe`를 내려받는다.
2. 실행하면 SmartScreen이 **"Windows의 PC 보호"** 창을 띄울 수 있다 (서명이 없어서 그렇다)
   → **추가 정보 → 실행**을 누른다.
3. 설치가 끝나면 시작 메뉴와 바탕화면에 등록된다.

### 파일 연결

설치 시 `.md`·`.markdown`·`.mdown` 확장자가 등록된다. 다른 앱이 이미 연결돼 있으면
파일 **우클릭 → 연결 프로그램 → 다른 앱 선택 → MD Viewer**에서 "항상 이 앱 사용"을 지정한다.

### 제거

**설정 → 앱 → 설치된 앱**에서 MD Viewer 제거. 설정까지 지우려면
`%APPDATA%\MD Viewer` 폴더를 삭제한다.

## 3. 설치 — Linux

**대상**: x86_64(64비트 PC). 두 가지 형식을 제공한다.

### 방법 A — AppImage (설치 없이 실행, 배포판 무관)

```bash
chmod +x MD-Viewer-*.AppImage
./MD-Viewer-*.AppImage
```

- 실행 파일 하나로 동작한다. 원하는 위치에 두고 그대로 쓰면 된다.
- **FUSE 오류**가 나면(`dlopen(): error loading libfuse.so.2`) 아래를 설치한다.

```bash
# Ubuntu / Debian
sudo apt install libfuse2

# Fedora
sudo dnf install fuse-libs
```

- FUSE를 설치하지 않고 실행하려면 압축을 풀어 직접 실행할 수도 있다.

```bash
./MD-Viewer-*.AppImage --appimage-extract
./squashfs-root/AppRun
```

### 방법 B — deb 패키지 (Ubuntu·Debian 계열)

```bash
sudo apt install ./MD-Viewer_*_amd64.deb
```

설치하면 애플리케이션 메뉴에 등록되고 `.md`·`.pdf` 파일 연결도 함께 설정된다.
제거는 다음과 같다.

```bash
sudo apt remove md-viewer
```

### 샌드박스 관련 실행 오류

일부 배포판에서 `SUID sandbox helper` 오류가 날 수 있다. deb로 설치하면 보통 발생하지 않지만,
압축을 풀어 실행하는 경우 아래로 우회한다.

```bash
./AppRun --no-sandbox
```

### 설정 위치

```
~/.config/MD Viewer
```

## 4. 처음 사용하기

앱을 실행하면 빈 화면에 **파일 열기 · 폴더 열기** 두 버튼이 있다. 목적에 맞게 고른다.

**문서 하나만 볼 때 — 파일 열기** (`⌘O` / `Ctrl+O`)

파일 선택 대화상자에서 `.md`·`.pdf`를 고른다. **여러 개를 선택하면 모두 탭으로 열린다.**

열려 있는 폴더 트리에 **없는** 문서(예: 내려받은 파일)는 사이드바 맨 위의
**따로 연 문서** 목록에 나타난다. **폴더 트리는 그대로 유지되고**, 그 파일이 있는 폴더가
통째로 열리지도 않는다 ([5절](#5-화면-구성) 참조).

**문서 묶음을 오가며 볼 때 — 폴더 열기** (`⇧⌘O` / `Ctrl+Shift+O`)

폴더를 고르면 하위 폴더까지 훑어 문서 트리를 만든다. 트리에서 문서를 클릭하면 탭으로 열리고,
전체 검색·연결 그래프도 그 폴더를 대상으로 동작한다.

다음에 앱을 다시 켜면 **마지막 폴더와 열려 있던 탭이 자동 복원**된다.

> 팁 1: 파일이나 폴더를 창에 **끌어다 놓아도** 열린다.
> 팁 2: 터미널에서 경로를 넘겨 바로 열 수도 있다 —
> macOS `open -a "MD Viewer" 문서.md`, Windows·Linux는 실행 파일에 경로를 인자로 준다.

## 5. 화면 구성

| 영역 | 설명 |
|------|------|
| **빈 화면** | 아무것도 열지 않은 상태. **파일 열기 · 폴더 열기** 버튼이 있다 |
| **사이드바 (왼쪽)** | 문서 트리. 폴더는 클릭해서 접고 펼친다. 위쪽에 `◎`(연결 그래프)와 **폴더 열기** 버튼 |
| **따로 연 문서** | 트리 밖에서 연 문서 목록. 트리 위에 나타나며 **해당하는 문서가 없으면 보이지 않는다** |
| **개요 / 백링크 탭** | 사이드바 하단. 두 탭을 전환한다. 헤더를 클릭하면 패널을 접는다 |
| **탭바 (위)** | 열려 있는 문서. 긴 이름은 말줄임되며 마우스를 올리면 전체 이름이 보인다. `×`로 닫는다 |
| **본문 (가운데)** | 렌더링된 문서 |
| **상태 바 (아래)** | 파일 경로 · 단어 수 · 파일 감시 상태 · **읽기/편집 모드** · 글자 크기(클릭하면 순환) · 테마 토글 |

### 따로 연 문서

폴더 트리와 **관계없는 문서**(내려받은 파일, 다른 폴더의 문서)를 열면 사이드바 맨 위에
이 목록이 생긴다. 폴더만 오가며 읽을 때는 목록 자체가 보이지 않는다.

- 항목을 클릭하면 그 문서로 이동한다. 지금 읽는 문서는 여기에서 **강조 표시**된다
- 항목에 마우스를 올리면 나오는 `×`로 닫는다 (탭도 함께 닫힌다)
- 앱을 다시 켜면 **이 문서들도 함께 복원된다**
- 나중에 그 문서가 든 폴더를 열면, 해당 항목은 목록에서 빠지고 트리에서 보인다

경계선을 드래그하면 크기를 조절할 수 있다 — **사이드바 좌우 폭**(더블클릭으로 초기화),
**트리와 개요 사이 높이**.

## 6. 기능별 사용법

### 6.1 개요(아웃라인) 패널

사이드바 하단 **개요** 탭. 현재 문서의 제목(H1~H6) 목록이 계층으로 표시된다.
항목을 클릭하면 해당 위치로 이동하고, 스크롤하면 현재 읽고 있는 제목이 강조된다.

### 6.2 백링크 패널

**백링크** 탭. **현재 문서를 `[[위키링크]]`로 참조하는 다른 문서들**을 참조된 줄과 함께
보여준다. 탭 이름 옆 숫자는 건수다. 항목을 클릭하면 그 문서로 이동한다.

### 6.3 연결 그래프

`⌘⇧G` / `Ctrl+Shift+G` 또는 사이드바의 `◎` 버튼.
폴더 전체의 문서를 점(노드)으로, `[[위키링크]]` 참조를 선으로 그린다.

| 조작 | 동작 |
|------|------|
| 노드 클릭 | 그 문서를 열고 그래프를 닫는다 |
| 노드에 마우스 올리기 | 그 문서와 직접 연결된 것만 강조, 나머지는 흐리게 |
| 노드 드래그 | 위치를 옮겨 고정한다 |
| 빈 공간 드래그 | 화면 이동 |
| 마우스 휠 | 확대·축소 |
| **전체 / 현재 문서 주변** | 전체 그래프와 현재 문서의 직접 이웃만 보기를 전환 |
| **재배치** | 배치를 처음부터 다시 계산하고 화면에 맞춘다 |
| `Esc` 또는 `×` | 닫기 |

- 점 크기는 **연결 수**에 비례한다. 연결이 많은 문서가 크게 보인다.
- 현재 열려 있는 문서는 **강조 색**으로 표시된다.
- 상단 정보에 `문서 / 연결 / 고립 / 미해결 링크` 수가 나온다.
  - **고립**: 어떤 문서와도 연결되지 않은 문서
  - **미해결 링크**: `[[...]]`로 가리켰지만 그 이름의 파일이 폴더에 없는 경우
- 코드 블록이나 인라인 코드 안의 `[[...]]`는 문법 예시로 보고 연결에서 제외한다.

### 6.4 문서 내 찾기

`⌘F` / `Ctrl+F`. 매치가 노란색으로 표시되고, 현재 매치는 강조 색이 된다.

| 조작 | 동작 |
|------|------|
| `Enter` / `⇧Enter` | 다음 / 이전 매치 |
| `Aa` 버튼 | 대소문자 구분 |
| `.*` 버튼 | 정규식 사용 (예: `E\d+_\w+`) |
| `Esc` | 닫기 |

- 문서에서 텍스트를 선택한 뒤 `⌘F`를 누르면 그 텍스트가 검색어로 들어간다.
- **PDF에서도 동작한다.**
- 잘못된 정규식은 입력창이 빨갛게 되고 "오류"가 표시된다.

### 6.5 전체 검색 (폴더 내 모든 문서)

`⌘⇧F` / `Ctrl+Shift+F`. 두 글자 이상 입력하면 폴더 내 모든 마크다운을 줄 단위로 검색한다.
결과는 파일별로 묶이고 줄 번호가 함께 나온다. 결과를 클릭하면 그 문서를 열고 해당 검색어를
문서 내 찾기로 이어서 표시한다. (결과 상한 300건)

### 6.6 PDF 열람

트리에서 `.pdf`를 클릭하면 탭으로 열린다. 앱 테마 배경 위에 페이지가 놓인다.

| 조작 | 동작 |
|------|------|
| `◀` `▶` | 이전 / 다음 페이지 |
| **페이지 번호 입력** | 번호 칸에 숫자를 넣고 `Enter` → 그 페이지로 이동. 범위를 넘으면 마지막 페이지로, 숫자가 아니면 원래 번호로 되돌아온다. `Esc`로 취소 |
| `−` `＋` | 축소 / 확대 (40~300%) |
| **맞춤** | 폭 맞춤으로 복귀 |
| 드래그 | 텍스트 선택·복사 |
| `⌘F` | 본문 검색 |

> 스캔한 이미지 PDF는 텍스트가 없어 검색·선택이 되지 않는다(그림은 정상 표시).

### 6.7 내보내기

| 형식 | 단축키 | 결과 |
|------|--------|------|
| **PDF** | `⌘E` / `Ctrl+E` | A4 인쇄용. 화면이 어두운 테마여도 **항상 흰 배경**으로 나온다 |
| **HTML** | `⌘⇧E` / `Ctrl+Shift+E` | 스타일·수식 폰트·이미지를 모두 담은 **파일 하나**. 인터넷 없이 어느 브라우저에서나 동일하게 열린다 |

HTML 내보내기는 남에게 문서를 보낼 때 쓴다 — 받는 사람이 이 뷰어를 설치하지 않아도 된다.

### 6.8 읽기 환경

| 항목 | 방법 |
|------|------|
| **읽기 폭** | 보기 메뉴 › 읽기 폭 (좁게 / 보통 / 넓게 / 창 전체) |
| **본문 글자 크기** | 보기 메뉴 › 본문 글자 크기, 상태 바의 `15px` 클릭, 또는 `⌘⌥+` / `⌘⌥−` |
| **다크 / 라이트 테마** | `⌘⇧L` / `Ctrl+Shift+L` 또는 상태 바의 달·해 아이콘 |
| **화면 전체 확대** | `⌘+` / `Ctrl++` (사이드바까지 함께 커진다) |

본문 글자 크기는 제목·표·코드까지 **비례해서** 커진다. 설정은 모두 기억된다.

### 6.9 업데이트

새 버전이 나오면 앱이 알려준다. **동작 방식이 OS별로 다르다.**

| 설치 형태 | 동작 |
|-----------|------|
| **Windows** (exe) | 새 버전을 **자동으로 내려받고**, "재시작하여 설치"를 누르면 적용된다 |
| **Linux — AppImage** | 위와 같이 **자동 내려받기·설치** |
| **macOS** (dmg) | **알림만** 한다. "다운로드 페이지 열기"를 눌러 새 dmg를 받아 교체한다 |
| **Linux — deb** | **알림만** 한다. 패키지 관리자로 새 deb를 설치한다 |

> macOS에서 자동 설치가 안 되는 이유: Apple의 업데이트 구조가 **코드 서명된 앱만** 허용한다.
> 이 앱은 서명이 없어 자동 설치가 거부되므로, 알림을 받고 직접 교체하는 방식이다.

- 확인 시점: 앱을 켠 뒤 한 번. 직접 확인하려면 **도움말 › 새 버전 확인**.
- 알림 바의 **자동 확인 끄기**를 누르면 이후 조회하지 않는다. 다시 켜려면 도움말 메뉴에서
  직접 확인하면 된다(끈 상태에서도 수동 확인은 동작한다).
- 자동 확인을 끄면 앱은 인터넷에 접속하지 않는다. 문서 렌더링은 애초에 인터넷과 무관하다.

### 6.10 파일 감시 (자동 새로고침)

열려 있는 문서를 외부 편집기(VS Code, Obsidian 등)에서 저장하면 **자동으로 다시 렌더링**된다.
읽던 스크롤 위치는 유지된다. 상태 바의 `watching: on`이 감시 중임을 뜻한다.

### 6.11 편집 모드

이 앱은 **기본이 읽기 전용**이다. 읽는 중에 오타를 발견했을 때만 잠깐 고치라고 만든 기능이며,
문서를 새로 쓰거나 파일을 관리하는 도구가 아니다 (파일 생성·이름 변경·삭제는 없다).

**켜기**: 상태 바 오른쪽의 **읽기** 버튼을 누르거나 `⌘⌥E` / `Ctrl+Alt+E`.
켜면 표시가 **편집**으로 바뀌고, 이 상태는 앱을 다시 켜도 유지된다.

| 조작 | 동작 |
|------|------|
| 블록 **더블클릭** | 그 블록의 원문이 그 자리에서 입력창이 된다 |
| 입력창 밖을 클릭 | **자동 저장**된다 (별도의 저장 조작이 없다) |
| `Esc` | 고친 내용을 버리고 닫는다 |
| `⌘Z` | 입력창 안에서 실행취소 |
| 상태 바 **되돌리기** | 이 문서를 **연 시점**으로 되돌린다 (그 뒤의 편집이 사라진다) |

- **편집 모드가 꺼져 있으면 더블클릭은 지금처럼 단어 선택**이다. 읽다가 실수로 문서가
  바뀌는 일이 없도록 모드를 나눠 두었다.
- 문단·제목·리스트·인용·표·코드 블록·수식·Mermaid **모두** 같은 방식으로 고친다.
  블록 단위로 **마크다운 원문**이 열리므로, 표는 파이프 표기가 그대로 보인다.
- 입력창을 나가면 즉시 다시 렌더링되므로 결과를 바로 확인하며 다듬을 수 있다.
- 저장은 **파일의 원래 줄바꿈 방식(LF/CRLF)을 그대로 유지**한다.
- PDF 탭은 편집 대상이 아니다.

> [!warning]
> **되돌리기는 앱을 켜 둔 동안만 유효하다.** 앱을 닫으면 기준점이 사라진다.
> 중요한 문서라면 볼트를 git이나 Time Machine 같은 백업 아래에 두는 편이 훨씬 안전하다.

#### 메모 달기

읽다가 **내 판단을 그 자리에 덧붙이고 싶을 때** 쓴다. 블록을 더블클릭해 편집창을 연 뒤
`⌘⇧M` / `Ctrl+Shift+M`을 누르면, **그 블록 바로 아래에 메모 상자가 생기고 커서가 들어간다.**
(보기 메뉴 › 메모 달기도 같은 동작이다.)

메모는 `> [!note]` 콜아웃으로 들어가므로 **화면에서 색으로 구분된다** — 나중에 다시 읽을 때
원래 문서와 내가 덧붙인 말이 섞이지 않는다.

#### 소스 모드 — 문서 전체 고치기

문단 하나가 아니라 **문서 구조를 손봐야 할 때** 쓴다. `⌘⌥S` / `Ctrl+Alt+S` 또는 상태 바의
**소스** 버튼(편집 모드일 때만 보인다).

| 조작 | 동작 |
|------|------|
| 진입 | 본문이 문서 전체의 **마크다운 원문**으로 바뀐다 |
| `⌘S` / `Ctrl+S` | **저장.** 상태 바의 **저장** 버튼을 눌러도 된다 |
| 다시 `⌘⌥S` | 소스 모드를 끄고 렌더링 화면으로 돌아온다 |

> [!important]
> **소스 모드는 자동 저장되지 않는다.** 인라인 편집과 달리 문서 전체를 한 번에 덮어쓰는
> 경로라, 저장을 직접 하도록 했다. 고친 내용이 있으면 상태 바에 **저장** 버튼이 나타난다.
>
> 저장하지 않은 채 소스 모드를 끄거나 탭을 옮기려 하면 **저장할지 묻는 창**이 뜬다.
> 확인 없이 그냥 넘어가는 일은 없다.

소스 모드로 편집하는 동안 그 문서가 외부에서 바뀌면, 화면을 갈아엎지 않고 상태 바에
알림만 표시한다 — 쓰던 내용을 잃지 않기 위해서다. 그대로 저장하면 외부 변경을 덮어쓴다.

### 6.12 의견 보내기

**도움말 › 의견·수정 요청 보내기…** 를 누르면 브라우저에 GitHub 이슈 작성 화면이 열린다.
**고쳤으면 하는 점을 한 줄만 적어도 된다.**

- 앱 버전·OS·아키텍처는 **자동으로 채워진다.** 문서 경로나 문서 내용은 첨부되지 않는다
- 제출하려면 GitHub 계정이 필요하다. 계정이 없다면 **도움말 › 환경 정보 복사**로
  환경 정보만 복사해 다른 경로로 전달해도 된다
- 저장소가 공개되어 있어 **작성한 내용도 공개된다.** 알려지면 곤란한 정보는 적지 않는다

## 7. 단축키

macOS는 `⌘`(Command), Windows·Linux는 `Ctrl`을 쓴다.

| 동작 | macOS | Windows · Linux |
|------|-------|-----------------|
| 파일 열기 | `⌘O` | `Ctrl+O` |
| 폴더 열기 | `⇧⌘O` | `Ctrl+Shift+O` |
| 문서 내 찾기 | `⌘F` | `Ctrl+F` |
| 전체 검색 | `⌘⇧F` | `Ctrl+Shift+F` |
| 연결 그래프 | `⌘⇧G` | `Ctrl+Shift+G` |
| 편집 모드 켜기 / 끄기 | `⌘⌥E` | `Ctrl+Alt+E` |
| 소스 모드 켜기 / 끄기 | `⌘⌥S` | `Ctrl+Alt+S` |
| 소스 모드 저장 | `⌘S` | `Ctrl+S` |
| 메모 달기 (편집창 안에서) | `⌘⇧M` | `Ctrl+Shift+M` |
| PDF로 내보내기 | `⌘E` | `Ctrl+E` |
| HTML로 내보내기 | `⌘⇧E` | `Ctrl+Shift+E` |
| 테마 전환 | `⌘⇧L` | `Ctrl+Shift+L` |
| 본문 글자 크게 / 작게 | `⌘⌥+` / `⌘⌥−` | `Ctrl+Alt++` / `Ctrl+Alt+−` |
| 화면 전체 확대 / 축소 / 원래대로 | `⌘+` / `⌘−` / `⌘0` | `Ctrl++` / `Ctrl+−` / `Ctrl+0` |
| 새로 고침 | `⌘R` | `Ctrl+R` |
| 전체 화면 | `⌃⌘F` | `F11` |
| 창 닫기 / 종료 | `⌘W` / `⌘Q` | `Alt+F4` |
| 찾기·검색·그래프 닫기 | `Esc` | `Esc` |

> 메뉴 위치: macOS는 화면 맨 위 메뉴 막대, Windows·Linux는 창 안쪽 상단 메뉴.

## 8. 문제 해결

| 증상 | 확인 / 해결 |
|------|-------------|
| **(macOS)** "손상되었으므로 휴지통으로 이동" | 서명 부재 때문이다. `xattr -dr com.apple.quarantine "/Applications/MD Viewer.app"` 실행 ([1절](#1-설치--macos)) |
| **(macOS)** Intel Mac에서 실행되지 않음 | 현재 Apple Silicon(arm64) 빌드만 제공한다 |
| **(Windows)** SmartScreen 경고 | **추가 정보 → 실행** |
| **(Linux)** `libfuse.so.2` 오류 | `sudo apt install libfuse2` 또는 `--appimage-extract`로 풀어 실행 ([3절](#3-설치--linux)) |
| **(Linux)** 샌드박스 관련 실행 실패 | deb로 설치하거나 `--no-sandbox`로 실행 |
| 업데이트 알림이 안 뜸 | 자동 확인이 꺼져 있을 수 있다. **도움말 › 새 버전 확인**으로 직접 확인한다 |
| **(macOS)** 업데이트가 자동 설치되지 않음 | 의도된 동작이다. Apple 서명이 없어 알림만 하며, 새 dmg를 받아 교체한다 ([6.9절](#69-업데이트)) |
| 앱이 켜지지 않고 아무 반응이 없음 | 이미 실행 중일 수 있다. 중복 실행을 막는 구조이므로 기존 창을 찾아본다 |
| 수식·다이어그램이 깨져 보임 | 문서의 문법 오류다. `$…$`·` ```mermaid ` 블록을 확인한다 |
| 트리에 문서가 안 보임 | 마크다운·PDF가 없는 폴더는 트리에서 숨긴다. 이름이 `.`으로 시작하는 폴더와 `node_modules`는 제외된다 |
| 백링크·그래프에 연결이 안 나옴 | 파일명을 텍스트로만 적으면 연결되지 않는다. `[[문서명]]` 형식으로 써야 한다 |
| PDF에서 검색·선택이 안 됨 | 스캔 이미지 PDF는 텍스트 정보가 없다 |
| 문서를 고칠 수 없음 | 기본이 읽기 전용이다. 상태 바의 **읽기**를 누르거나 `⌘⌥E`로 편집 모드를 켠다 ([6.11절](#611-편집-모드)) |
| 실수로 고쳐서 저장됐다 | 편집 중이면 `⌘Z`, 이미 저장됐으면 상태 바의 **되돌리기**로 문서를 연 시점으로 되돌린다 |
