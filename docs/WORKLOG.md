## 2026-08-01 (v0.14.0 — 콜아웃 접기)

- **목표**: "메모 여러 개 달아보니 읽기 흐름이 좀 끊긴다"는 실사용 피드백 해소.
- **코드에서 찾은 유리한 사실**: `calloutPlugin`의 정규식이 **이미 `[+-]`(접기 표기)를 잡고 있었는데
  `m[2]`를 쓰지 않고 버리고 있었다.** 새 문법을 만든 게 아니라 미완성 지원을 완성한 셈이다.
- **결정사항**: [[DECISIONS|D44~D46]]. 접기 채택(일괄 숨기기·각주식 모으기는 **"메모가 있다"는 신호까지
  지워** 기각, 여백 배치는 읽기 폭과 충돌). **모든 콜아웃**을 클릭으로 접을 수 있게 해
  이미 달아둔 메모가 문서 수정 없이 즉시 혜택을 보게 했다.
- **산출물**: `> [!note]-` 초기 접힘 · 제목 클릭 토글(`▾`/`▸`) · 메모 삽입을 `-` 표기로 변경 ·
  [[AI-AUTHORING]]에 접기 문법 안내 추가.
- **검증(CDP, 예외 0건)**: `-` 표기는 접힌 채 시작하고 표기 없는 콜아웃은 펼쳐진 채 시작 /
  접힌 것을 클릭하면 펼쳐짐 / **표기 없는 기존 메모도 클릭으로 접힘** / 문서 불변 /
  새로 단 메모가 `> [!note]-`로 저장되고 접힌 상태로 렌더.
- **알아둘 동작**: 메모를 쓰고 편집창을 나오면 **바로 접힌다**(내용이 사라진 것이 아님).
  접기가 목적이므로 의도된 동작이며, 사용설명서에 명시했다.
