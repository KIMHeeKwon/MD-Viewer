디자인 시스템 개요

이 프로젝트에 바인딩된 KKOBAK(HKDS)의 컬러·타이포그래피·간격·컴포넌트 정보입니다. 원본은 다크 전용이며, 라이트 테마는 동일한 토큰 이름 위에 밝은 값을 덮어써 DS 컴포넌트까지 함께 전환됩니다.

사용 규칙 요약
  • HKDS 원본은 다크 전용 — ThemeProvider가 감싼 영역에 data-theme="light"를 걸면 같은 토큰 위에 밝은 값이 덮여 라이트로 전환됩니다.
  • 유틸리티 클래스 없음 — 스타일은 컴포넌트 props와 vars 토큰으로만
  • CSS 변수명은 해시되어 불안정 — 코드에서는 window.HKDS.vars 로 참조
  • 포인트 컬러 2종: accent(teal) · accent2(violet) — 라이트에서는 채도를 낮추고 명도를 내려 조정
