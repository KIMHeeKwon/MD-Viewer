# MD Viewer

**한국어**: 현재 문서 · **English**: [README.en.md](README.en.md)

작성자의 의도대로 마크다운을 렌더링하는 **단독 실행 데스크톱 뷰어**. macOS · Windows · Linux 지원, 완전 오프라인 동작.
**읽기 중심 뷰어**입니다 — 기본은 읽기 전용이고, 필요할 때만 편집 모드를 켜서 고칩니다.

GitHub Flavored Markdown에 수식(KaTeX) · 다이어그램(Mermaid) · 코드 하이라이트 · Obsidian 확장(`[[위키링크]]`, 콜아웃)까지 지원하며, 폴더 트리와 다중 탭으로 여러 문서를 한 번에 탐색합니다.

## 이런 용도로 만들었습니다

**LLM과의 대화로 정리한 자료를 다시 읽기 위한 뷰어**입니다. 시스템 설계나 특정 주제를
AI와 논의하며 마크다운으로 정리하다 보면, 수식·다이어그램·문서 간 참조가 섞인 문서가
빠르게 쌓입니다. 이 문서들을 **작성자의 의도대로, 폴더 단위로 오가며** 읽는 것이 목표입니다.

그래서 **AI에게 어떻게 요청하면 이 뷰어에서 제대로 보이는 마크다운이 나오는지**를
별도 지침으로 정리해 두었습니다 — 복사해서 쓰는 프롬프트 블록, 지원 문법 범위,
LLM이 자주 넣지만 렌더링되지 않는 것들(원시 HTML 등), 문서를 오래 쌓아갈 때의 파일·폴더 규약:

**→ [AI와 함께 쓰는 마크다운 작성 지침](docs/AI-AUTHORING.md)**

설치·사용법·단축키를 OS별로 정리한 안내서도 있습니다:
**→ [사용설명서 (macOS · Windows · Linux)](docs/USER-GUIDE.md)**

## 주요 기능

- **폭넓은 문법 지원** — GFM(표 · 작업 목록 · 취소선 · 각주), KaTeX 수식, Mermaid 다이어그램, 코드 신택스 하이라이트, Obsidian 위키링크 · 콜아웃
- **파일 단위 열기 (⌘O)** — 문서 하나만 빠르게 열람. 여러 개를 선택하면 모두 탭으로 열림
- **따로 연 문서** — 폴더 트리 밖에서 연 문서(내려받은 파일 등)는 사이드바 위쪽 별도 목록에 모임. **폴더 트리는 흔들리지 않고**, 해당 문서가 없으면 목록도 보이지 않음
- **폴더 트리 + 다중 탭 (⇧⌘O)** — 폴더를 열면 사이드바에 문서 트리가 표시되고, 문서를 탭으로 여러 개 열람. 사이드바 폭은 드래그로 조절되며 기억됨
- **개요(아웃라인) 패널** — 사이드바 하단에 문서 헤딩 목록. 클릭으로 점프하고 스크롤에 따라 현재 위치 표시
- **백링크 패널** — 현재 문서를 `[[위키링크]]`로 참조하는 다른 문서 목록. 클릭하면 그 문서로 이동
- **연결 그래프 (⌘⇧G)** — 폴더 전체의 문서 연결 관계를 그래프로 시각화. 노드 클릭으로 이동, 현재 문서 주변만 보기, 확대·이동 지원
- **드래그앤드롭** — 파일이나 폴더를 창에 끌어다 놓으면 바로 열림
- **문서 내 찾기 (⌘F)** — 매치 하이라이트, 개수 표시, 이전/다음 이동. **정규식**·**대소문자 구분** 옵션 지원, **PDF 본문도 검색**
- **읽기 폭 조절** — 보기 메뉴에서 좁게/보통/넓게/창 전체 선택 (설정 유지)
- **본문 글자 크기** — 제목·표·코드까지 비례 확대. 보기 메뉴, 상태 바 클릭, `⌘⌥+`/`⌘⌥-`로 조절 (UI 크기는 그대로)
- **전체 검색 (⌘⇧F)** — 폴더 내 모든 마크다운을 가로질러 검색, 결과 클릭으로 해당 문서로 이동
- **세션 복원** — 앱을 다시 켜면 마지막 폴더와 열려 있던 탭을 자동 복원
- **파일 연결** — Finder/탐색기에서 `.md` 파일을 더블클릭하면 MD Viewer로 열림 (설치 후 활성화)
- **PDF** — PDF 파일 열람(앱 테마에 통합, 페이지 이동 · **번호 입력 이동** · 확대/축소 · 텍스트 선택 및 검색) 및 마크다운 → PDF 내보내기(⌘E, 항상 라이트 테마로 출력)
- **HTML 내보내기 (⌘⇧E)** — 스타일 · 수식 폰트 · 이미지를 모두 내장한 **파일 하나짜리 HTML**. 인터넷 없이 어느 브라우저에서나 동일하게 열림
- **편집 모드 (⌘⌥E)** — 기본은 읽기 전용. 켜면 문단·표·코드 블록을 **더블클릭해 그 자리에서** 원문을 고치고, 빠져나오면 자동 저장·재렌더링. 상태 바의 **되돌리기**로 문서를 연 시점으로 복귀
- **메모 달기 (우클릭 또는 ⌘⇧M)** — 블록 아래에 `> [!note]` 콜아웃을 끼워 넣어 내 판단을 덧붙입니다. **색으로 구분되어** 원문과 섞이지 않습니다
- **소스 모드 (⌘⌥S)** — 문서 전체의 마크다운 원문을 고칩니다. 자동 저장이 아니라 **`⌘S` 명시 저장**이며, 저장하지 않고 나가려 하면 확인합니다
- **파일 감시** — 외부 편집기(VS Code, Obsidian 등)에서 문서를 저장하면 자동으로 다시 렌더링
- **다크 / 라이트 테마** (⌘⇧L)
- **오프라인 렌더링** — 폰트 · 스크립트 전부 번들. 인터넷 없이도 문서가 똑같이 보입니다
- **업데이트 확인** — 새 버전이 나오면 알려줍니다(Windows · Linux AppImage는 자동 설치). 끌 수 있습니다

## 설치

[Releases](https://github.com/KIMHeeKwon/MD-Viewer/releases/latest)에서 플랫폼에 맞는 파일을 내려받습니다.

| 플랫폼 | 파일 |
|--------|------|
| macOS (Apple Silicon) | `MD-Viewer-<버전>-arm64.dmg` |
| Windows | `MD-Viewer-Setup-<버전>.exe` |
| Linux | `MD-Viewer-<버전>.AppImage` (실행 권한 부여 후 바로 실행) 또는 `.deb` |

### 처음 실행 시 경고 해결 (macOS)

이 앱은 Apple 코드 서명·공증이 없어, 처음 실행할 때 macOS가 경고를 띄웁니다. 앱이 손상된 것이 아니라 인터넷에서 받은 파일에 붙는 **격리(quarantine) 속성** 때문입니다.

- **"확인되지 않은 개발자" 경고**: 앱을 **우클릭 → 열기** → 대화상자에서 **열기**. (한 번만 하면 이후엔 그냥 열림)
- **"손상되었으므로 휴지통으로 이동" 경고**: 아래 명령으로 격리 속성을 제거한 뒤 실행합니다.

```bash
xattr -dr com.apple.quarantine "/Applications/MD Viewer.app"
```

Windows에서는 SmartScreen이 "Windows의 PC 보호" 창을 띄울 수 있습니다 → **추가 정보 → 실행**을 누르면 됩니다.

## 의견 보내기

앱의 **도움말 › 의견·수정 요청 보내기…**를 누르면 GitHub 이슈 작성 페이지가 열립니다.
앱 버전과 OS는 자동으로 채워지며, **고쳤으면 하는 점을 한 줄만 적으셔도 됩니다.**
(문서 경로나 문서 내용은 자동으로 첨부되지 않습니다.)

GitHub 계정이 없다면 **도움말 › 환경 정보 복사**로 환경 정보만 복사해 다른 경로로 알려 주셔도 됩니다.

## 개발

```bash
npm install
npm start          # 렌더러 번들 후 Electron 실행
```

빌드 · 패키징:

```bash
npm run bundle     # esbuild로 렌더러 번들
npm run dist       # electron-builder로 설치 파일 생성
```

릴리스는 `v*` 태그를 push하면 GitHub Actions가 macOS · Windows · Linux 설치 파일을 자동 생성합니다.

### 기술 스택

Electron · markdown-it · KaTeX · Mermaid · highlight.js · PDF.js · chokidar · esbuild
